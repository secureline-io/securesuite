# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment. We are a community of security researchers building a commons — treat each other accordingly. This is offensive-security tooling; keep discussion focused on authorized, lawful use.

Report conduct concerns privately to the maintainers via the contact listed in the repository. Maintainers will respond and may take any action they deem appropriate, up to and including a ban.
